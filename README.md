# YouTalk — Блог

Адаптивная вёрстка блога сервиса психологической помощи YouTalk по макету Figma.

## Страницы
- `index.html` — страница блога (лента статей с фильтром по темам).
- `article.html` — страница статьи с боковым блоком `aside` и CTA-секцией.

## Структура
- `css/style.css` — стили (методология **БЭМ**, desktop-first + медиа-запросы).
- `js/menu.js` — переключение мобильного меню (бургер).
- `icons/` — иконки в формате **SVG** (логотип, соц-сети, стрелки и т.д.).
- `images/` — фотографии и иллюстрации в формате **PNG**.

## Адаптив
- Десктоп (> 1024px): полное меню, сетка карточек 3 колонки.
- Планшет (≤ 1024px): бургер-меню, 2 колонки, крупные карточки на всю ширину; `aside` статьи переносится под контент.
- Мобильные (≤ 767px): одна колонка, вертикальная раскладка.

## Локальный запуск
```bash
python3 -m http.server 4178
# затем открыть http://localhost:4178/index.html
```
